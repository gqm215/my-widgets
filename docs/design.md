# 墨集 · 设计规范（Design Spec）

> 适用范围：`src/` 下所有页面、布局与 UI 组件。本文档描述「应该长什么样、怎么交互」，实现以代码为准；新增组件/页面时先在此登记规范，再写实现。

## 1. 设计原则

1. **墨色纸韵**：宣纸白为底、墨色为字、朱砂为强调；装饰克制，信息优先。
2. **一屏一事**：每个页面只承担一个主任务，筛选、排序、新建都围绕它组织。
3. **即时反馈**：任何写操作（增/删/改/导入/导出）都必须有可见反馈（Toast、行内错误或状态变化）。
4. **可预测**：同一类操作在所有页面行为一致——删除必确认、弹窗必可 ESC/点遮罩关闭、表单错误就地提示。
5. **可离线**：不依赖远程字体、图片与接口；所有资源本地化（PWA 缓存）。
6. **可访问**：键盘可达、焦点可见、图标按钮有可读名称、动效尊重 `prefers-reduced-motion`。

## 2. 设计令牌

### 2.1 色彩

| 令牌 | 值 | 用途 |
|---|---|---|
| `ink-900` | `#1a1a1a` | 标题、主文字（暗色模式为底色） |
| `ink-800` | `#242424` | 暗色模式卡片 |
| `ink-700` | `#2d2d2d` | 正文、暗色模式强调底 |
| `ink-500` | `#4a4a4a` | 次级正文 |
| `ink-400` | `#6b6b6b` | **纸白上的小号辅助文字**（对比度 ≥ 4.5:1） |
| `ink-300` | `#8a8a8a` | 仅用于大字号/装饰/暗色模式辅助文字 |
| `ink-100` | `#e8e8e8` | 深色背景上的正文 |
| `vermilion` | `#c94043` | 主操作、危险操作、今日标记 |
| `rattan` | `#d4a84b` | 日程、次强调、收藏 |
| `success` | `#5a9a6e` | 完成态、成功提示 |
| `paper` | `#faf8f5` | 页面底色 |
| `paper-dark` | `#f0ece4` | 分隔线、输入框描边 |
| `paper-accent` | `#f5f0e6` | 表头、弱底色 |

规则：
- 正文对比度 ≥ 4.5:1；小号辅助文字用 `ink-400`，不要用 `ink-300`。
- 朱砂只用于「主操作 / 危险 / 今日 / 强调」，同屏不超过两处大面积使用。
- 暗色模式一律通过 `dark:` 变体，不写 JS 条件样式。

### 2.2 字体

```
标题：font-serif → "Noto Serif SC", "Songti SC", "Source Han Serif SC", "SimSun", serif
正文：font-sans  → "Noto Sans SC", "PingFang SC", "Microsoft YaHei", system-ui, sans-serif
英文点缀：font-crimson → "Crimson Pro", "Georgia", serif
```

- 不引入远程字体（离线优先）；字体缺失时按上述回退，禁止依赖单一字体。
- 标题字重 600，正文 400，辅助文字 400/500。
- 正文行高 1.65，笔记预览行高 1.75。

### 2.3 间距与圆角

- 间距基数 4px：`2/3/4/6/8`（8/12/16/24/32px）为主。
- 页面内边距：桌面 `p-8`，移动 `p-4`；列表卡片间距 `space-y-3`/`space-y-4`。
- 圆角：小控件 `rounded-md`(8px)、卡片 `rounded-lg`(8px)/`rounded-xl`(12px)、弹窗 `rounded-2xl`(16px)、徽标 `rounded-full`。
- 卡片安全边距：`p-4`（紧凑）/`p-5`（常规）/`p-6`（详情）。

### 2.4 阴影与层次

| 令牌 | 用途 |
|---|---|
| `shadow-paper` | 常规卡片 |
| `shadow-paper-lg` | 悬停/浮层 |
| `shadow-paper-xl` | 弹窗 |
| `shadow-glow-vermilion` | 主按钮悬停 |

暗色模式不使用投影，改用 `border-white/[0.03]`～`white/[0.07]` 描边表达层次。

### 2.5 动效

| 场景 | 时长/曲线 |
|---|---|
| 页面切换 | 200ms `ease-out`，淡入 + 位移 20px |
| 列表项入场 | 200–350ms，按索引 stagger 40–60ms |
| 弹窗 | 240ms `cubic-bezier(0.22,1,0.36,1)`，scale 0.96→1 + fade |
| 抽屉（移动端） | 250ms 右侧滑入 |
| 删除退场 | 200ms 上移淡出后再触发删除 |
| 悬停抬升 | 280ms，位移 -2px |

- 全局 `prefers-reduced-motion: reduce` 时动效时长降至 0.01ms（`src/index.css`）。
- 不用弹跳/回弹曲线；动效只服务于「从哪里来、到哪里去」。

## 3. 布局与响应式

### 3.1 断点

| 名称 | 宽度 | 布局 |
|---|---|---|
| 移动 | `< 768px` | 底部/侧滑导航，单列，页面全宽 |
| 平板 | `768–1023px` | 侧栏 + 主内容，日历详情为抽屉 |
| 桌面 | `≥ 1024px` | 侧栏 + 主内容 + 可选右侧详情面板 |
| 宽屏 | `≥ 1280px` | 主内容最大宽度约束（表单页 `max-w-2xl`/`max-w-3xl`） |

### 3.2 应用外壳

- 左侧固定 `w-64` 墨色侧栏（Logo、导航、主题切换、设置）；移动端为右侧滑入抽屉 + 遮罩。
- 桌面 Topbar：日期 + 全局搜索 +「新建」。
- 移动端头部：汉堡按钮 + 标题 +「新建」。
- 主内容区独立滚动，页面切换有淡入过渡；笔记页与搜索页隐藏 Topbar（自成布局）。
- 卡片列表页统一 `max-w-3xl mx-auto`，阅读类页面 `max-w-2xl`。

## 4. 组件规范

### 4.1 Button
- 变体：`primary`（朱砂，主操作）、`secondary`（墨色）、`ghost`（次要/取消）、`danger`（同 primary 但用于破坏性）、`outline`（导出等中性操作）。
- 尺寸：`sm`（行内）、`md`（默认）、`lg`（空状态主行动）。
- 必须有 `focus-visible` 环；禁用态 `opacity-50` 且不可点击；`active:scale-[0.97]`。

### 4.2 Modal
- 结构：遮罩（`bg-ink-900/40` + blur）+ 面板（`max-w-md`，可通过 `className` 覆盖宽高）。
- 行为：打开时初始聚焦面板或首个可聚焦元素；`Tab/Shift+Tab` 焦点陷阱；`ESC`、点遮罩、关闭按钮均可关闭；关闭后焦点归还触发元素；背景滚动锁定。
- 语义：`role="dialog"`、`aria-modal="true"`、`aria-labelledby` 指向标题；无标题时用 `ariaLabel`。
- 表单弹窗的按钮固定右下：取消（ghost）+ 确认（primary/danger）；确认在必填未满足时禁用。

### 4.3 ConfirmDialog
- 删除/重置等不可逆操作必须使用；文案 = 动作 + 后果 + 「此操作不可撤销」。
- 危险操作用 `variant="danger"`，确认按钮文案为具体动作（「删除」「重置」），不用「确定」。

### 4.4 Toast
- 类型：`success` / `error` / `warning` / `info`；底部居中，3s 自动消失，可手动关闭，最多叠加 3 条（超出丢弃最旧）。
- 使用场景：增删改成功、导入/导出结果、标签操作、校验失败的补充说明。
- 不用于：表单字段级错误（用 `Input error` 行内提示）、破坏性操作确认（用 ConfirmDialog）。

### 4.5 EmptyState
- 必须包含：标题（说明「没有」什么）、描述（如何产生第一条数据）、行动按钮（可选）。
- 备忘空状态使用水墨场景图（`scene`），其余用线性图标。
- 列表无数据 ≠ 筛选无结果：筛选无结果时文案为「没有匹配的…」，并提供清除筛选的引导。

### 4.6 Badge / Card
- Badge：优先级/状态标签，`vermilion` 高、`rattan` 中、`success` 完成、`default` 低/中性。
- Card：`accent` 顶部渐变条用于强调（今日概览）；`hoverable` 仅用于可点击卡片；暗色模式用描边替代阴影。

### 4.7 Input / Textarea
- 有 `label` 时自动关联 `htmlFor/id`；`error` 展示在下方并同时设置 `aria-invalid`。
- 聚焦环 `ring-vermilion/15` + 描边加深；占位符 `ink-300`（暗色 `ink-500`）。

### 4.8 QuickCreate（全局新建）
- 桌面挂在 Topbar「新建」，移动端挂在头部「+」；点击展开四类：笔记、备忘、待办、日程。
- 选择后跳转 `/<module>?new=1`，目标页打开对应创建入口并清除查询参数（`replace`）。
- 键盘：`Tab/Shift+Tab` 在菜单项间移动（原生按钮语义）、`Enter` 选择、`Esc` 关闭；菜单项带图标与中文名称。

### 4.9 日历详情面板 / 抽屉
- 桌面：右侧 `w-72` 常驻面板，展示当日日程与待办，底部「添加待办 / 添加日程」。
- 移动：点击日期弹出底部/侧滑抽屉（含遮罩），内容与桌面一致，关闭后回到网格。
- 空态：当日无事项时展示 EmptyState + 添加按钮。

### 4.10 PageLoading
- 懒加载页面统一转圈 + 「加载中」，`role="status"`；禁止空白闪烁超过 200ms。

## 5. 页面规范

| 页面 | 主任务 | 布局要点 | 关键交互 |
|---|---|---|---|
| 今日 `/` | 看今天 | 山水横幅 + 三张统计卡 + 待办/日程双列 | 勾选完成、展开待办详情、跳日历查看日程 |
| 笔记 `/notes` | 写与找 | 左列表（收藏分组、标签筛选、虚拟滚动）+ 右双栏编辑/预览 | 新建、选中同步 URL、标签增删、防抖保存、删除确认、移动端单栏切换 |
| 备忘 `/memos` | 速记 | 顶部大输入 + 时间线列表 | 回车添加、转待办、转日程（弹窗）、删除确认 |
| 待办 `/todos` | 规划执行 | 标题 + 新建 + 筛选/排序工具条 + 列表 | 勾选、筛选（状态/优先级）、排序（创建/截止/优先级）、新建弹窗、删除确认 |
| 日程 `/events` | 管理事件 | 列表（按开始时间排序）+ 新建/编辑弹窗 | 全天/时段、重复、地点、校验、编辑、删除确认 |
| 日历 `/calendar` | 时间视图 | 工具条（前后/今天/月-周切换）+ 网格 + 详情 | 选日期、快速添加待办/日程、循环事件展示、移动抽屉、`?date=` 定位 |
| 周报 `/report` | 回顾 | 周次切换 + 四统计卡 + 活动分布条 + 模块详情 + 日程概览 | 翻周、导出 Markdown |
| 设置 `/settings` | 配置与数据 | 外观、标签管理、数据管理、关于 | 主题切换、标签增改删（改名级联）、导入/导出/重置 |
| 搜索 `/search` | 定位内容 | 返回 + 搜索框 + 分组结果 | 关键词高亮、点击跳转、回车更新 URL |

统一规则：
- 页面标题 `text-2xl font-serif font-semibold`；页面主操作在标题右侧。
- 日期展示：`yyyy年M月d日 EEEE`（中文），时间 `HH:mm`，日键 `yyyy-MM-dd`。
- 周起始为周一；周报范围为周一 00:00:00.000 ~ 周日 23:59:59.999。

## 6. 状态与反馈模式

| 状态 | 呈现 |
|---|---|
| 加载 | PageLoading / 懒加载 Suspense |
| 空 | EmptyState（标题 + 描述 + 可选行动） |
| 筛选无结果 | EmptyState 变体 + 引导清除筛选 |
| 校验失败 | 字段行内错误 + 确认按钮禁用；不弹 Toast |
| 操作成功 | Toast success（1 条即可，避免刷屏） |
| 操作失败 | Toast error + 保留用户输入 |
| 存储不可用 | 应用继续可用（内存态），控制台告警，不阻断交互 |
| 离线/可安装/有新版本 | PWARegister 底部提示条（安装、已离线、刷新更新） |
| 渲染异常 | ErrorBoundary 全屏「墨染残卷」+ 重试 |

## 7. 无障碍规范

- 所有图标按钮提供 `aria-label`（删除、收藏、关闭、上/下月等）。
- 可勾选待办使用 `role="checkbox"` + `aria-checked`，或原生 `<input type="checkbox">`。
- 表单字段有可见 `label` 且与控件关联；错误信息可被读屏感知（`aria-invalid`）。
- 弹窗焦点陷阱与归还（见 4.2）；抽屉同理。
- 键盘路径：`Tab` 可达所有操作；`Enter` 提交表单/确认；`Esc` 关闭浮层。
- 颜色不作为唯一信息载体（优先级同时有文字标签）。
- 动效遵循 `prefers-reduced-motion`。
- 焦点环统一 `focus-visible:ring-2 ring-vermilion/40`，禁止 `outline: none` 后无替代。

## 8. 暗色模式

- 通过 `html.dark` + Tailwind `darkMode: 'class'`；主题持久化在 `localStorage.theme`，默认跟随系统。
- 暗色下：背景 `ink-900`、卡片 `ink-800`、描边 `white/[0.03–0.07]`、文字 `ink-100/ink-300`；不使用阴影。
- 图片/场景图暗色下降低亮度（`dark:brightness-75`）并去饱和。
- 朱砂/藤黄在暗色下使用 `-light` 变体保证对比度。

## 9. 文案规范

- 中文为主，语气克制、书面化；避免感叹号堆叠。
- 按钮用动词（「新建」「保存」「删除」「导出」）；空状态给下一步动作。
- 破坏性文案必须写清后果；时间与数量带单位（「3 篇笔记」「2 项」）。
- 日期中文格式统一；英文只用于装饰性副标题（MO·JI）。

## 10. 变更流程

1. 新增颜色/间距/阴影令牌 → 先改 `tailwind.config.js` 与本文件，再使用。
2. 新增 UI 组件 → 放入 `src/components/ui/`，在 `index.ts` 导出，补 `__tests__`。
3. 新增页面 → 复用第 5 节模式，补空状态、加载、错误与移动端布局。
4. 任何交互变更 → 同步更新 `docs/testing.md` 的场景清单与对应测试。
