格式遵循 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，版本号遵循语义化版本。

## [Unreleased]

### 2.0.0（待发布）

#### 新增

- 清单体系：清单栏集中管理全部待办，内置「今天 / 最近 7 天 / 收集箱」智能清单；用户清单支持新建时选色、随时改名与删除（删除清单时其中任务自动移入收集箱，不会丢失）。
- 待办三栏布局：清单栏、任务列表、详情栏并排协作，窄屏自动切换为双抽屉。
- 任务详情编辑：标题内联编辑、截止日期、Markdown 描述（编辑 / 预览双态）、子任务管理、放弃与恢复。
- 智能过滤视图：今天、最近 7 天自动汇集，逾期任务红组置顶；已完成 / 已放弃折叠分组收纳，不干扰主列表。
- 优先级四档（无 / 低 / 中 / 高）筛选，配合按创建 / 截止 / 优先级排序。
- 笔记公式渲染：支持行内 `$…$` 与块级 `$$…$$` 公式（KaTeX 本地字体，完全离线可用）。
- 笔记高亮：`==文字==` 一键高亮；六色文字 / 高亮（朱砂、藤黄、青碧、黛蓝、藕荷、墨灰），基于类名白名单的安全渲染，自动适配暗色模式。
- 编辑器工具条：加粗、斜体、高亮、六色、无序列表、待办列表、公式一键插入；支持 `Ctrl+B`（加粗）与 `Ctrl+Shift+H`（高亮）快捷键；笔记编辑器与待办详情描述编辑均可用。
- 清单六色板：新建清单可选六色标识，暗色模式全部使用提亮变体保证辨识度。

#### 变更

- 数据模型升级至 v2：打开旧数据时自动完成迁移，「已完成」标记升级为「进行中 / 已完成 / 已放弃」三态，原完成时间保留，旧数据零丢失、无需手动操作。
- 新建待办默认归入收集箱，可随时移入清单。
- 新建待办默认无优先级，需要时再标记。
- 原按状态筛选入口由「已完成 / 已放弃」折叠分组取代，进行中任务始终一目了然。

#### 已知限制

- 行内公式 `$…$` 的成对匹配为渲染引擎固有语义：旧笔记中偶然成对的 `$` 符号会被呈现为公式，笔记原文不做任何改动。
- `==高亮==` 跨行内元素（如包住公式）的补配对要求 `==` 与前文紧邻书写，`== 公式 ==` 这类带空格的写法不会生效。
- 「今天 / 最近 7 天」视图不提供内联添加，请新建待办后移入或到收集箱、清单视图使用内联添加。
