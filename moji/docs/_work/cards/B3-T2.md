## 实现要点

1. `insertSyntax.ts` 纯函数：`applyInsert(action, text, selStart, selEnd) → { text, selStart, selEnd }`。动作集：加粗 `****`、斜体 `__`（可选）、无序列表 `- `、待办 `- [ ] `、高亮 `====`、颜色（6 色各一 → `<mark class="c-*">…</mark>`）、行内公式 `$$`、块级公式 `$$\n\n$$`。选中文字 → 包裹；无选中 → 插入语法对并把光标放中间；重复包裹防抖（已包裹则解除，尽力而为，测试锁定所选行为）。
2. EditorToolbar：按钮组（lucide 图标 + aria-label + title 提示语法），颜色按钮展开六色小面板（aria-pressed 当前色，样式对齐 ListRail 改色面板交互模式）；「选中浮现」要求（gaps D6）：textarea 有选中文本时工具条高亮可用态，无选中常显禁用态亦可（自选，交接说明）。
3. Notes 接线：编辑态 textarea 上方渲染工具条；快捷键建议 Ctrl+B 加粗、Ctrl+Shift+H 高亮（冲突自查，测试锁定；不影响全局已有快捷键）。
4. TaskDetail 接线：描述「编辑」态 textarea 上方渲染同一工具条（复用组件，不复制逻辑）。
5. 预览同步：插入后 onChange 即走既有防抖保存链，预览（B3-T1b 渲染链）自动反映——测试断言「插入高亮语法 → 预览出现对应 mark 类」。
6. 测试：insertSyntax 纯函数全覆盖（包裹/插入/光标位置/解除）；工具条点击 → textarea 值变化；快捷键触发；Notes 与 TaskDetail 两处冒烟；暗色下六色按钮可辨识（类名/令牌断言，手工核查留给 B7 QA）。
