## 实现要点

1. **?task= 双向同步（D9）**：
   - 加载：`?task=<id>` 且任务存在 → 选中（宽屏渲染详情栏；窄屏开详情抽屉）；任务不存在 → replace 清参数
   - 切换 `?list=` 时选中任务不属于新视图 → 清选中与参数；删除任务 → 清选中与参数
   - 点行选中 / 再点取消 → 写/清参数；窄屏关闭详情抽屉 → 清参数
2. **TaskDetail 内容**：
   - 标题：常驻 Input + blur/Enter 提交 → `updateTodo`（Esc 还原；空标题不提交）
   - 日期：原生 date input（样式化）→ `updateTodo dueDate`（清空日期 → 移除字段）
   - 提醒占位行：禁用态「提醒：未设置」+ title 提示 + 小字「提醒调度将在 B5 接入」
   - 描述：编辑（Textarea）/预览（react-markdown + remark-gfm）显式双按钮切换；原文存 `description`；保存走 `updateTodo`
   - 子任务：列表（勾选 `toggleTodo`；hover 删除按钮 `deleteTodo`）+ 底部「添加子任务」内联输入（`addSubtask`，回车连续添加）
   - 优先级：4 档分段选择（无/低/中/高）→ `updateTodo priority`
   - 状态操作：放弃 `abandonTodo` / 恢复 `restoreTodo`（仅顶层任务显示）；completed 任务提供「标记为进行中」（走 `updateTodo status:'active'` 或 `toggleTodo`，自选并交接说明）；删除（ConfirmDialog：有子任务时文案「其下 N 个子任务将一并删除」；删除后 Toast）
3. **viewKeys**：`?task=` 解析纯函数（非法值/缺失回落无选中）+ 单测。
4. **测试**：TaskDetail 交互（标题编辑提交、优先级切换、子任务增删勾、放弃/恢复、删除确认文案、描述双态）+ URL 同步（?task= 选中还原、非法 task 清参、切清单清 task）。
