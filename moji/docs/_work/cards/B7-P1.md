## 目标

重绘 `public/scenes/mountains-hero.svg`：保留水墨意境，解决锯齿、糊化、悬空残影三个具体问题。亮暗双主题下走查通过。

## 现状病因（已由主控定位）

1. 三层山全部是 `L` 直线段折线（等距三角波，机械感强）+ `feGaussianBlur stdDeviation=2.5`，横幅拉伸到约 1740px 宽时又锯齿又糊。
2. `translate(560,262)` 处的「小舟+渔线」剪影只有 14px，被 slice 裁切 + 模糊后成为悬空小三角残影。
3. 顶部两枚 mist 椭圆 + blur 在暗色主题下糊成脏雾带。
4. 矢量图本身不会糊——糊感来自 blur 滤镜滥用，不是分辨率问题。

## 重绘要点

1. **山脊改贝塞尔曲线**（Q/C），主峰高耸 + 侧峰错落 + 远峰绵延，打破等距三角波；3–4 层纵深，远山淡近山浓（墨色五阶：远 #6a6a6a→近 #1a1a1a 区间按层配透明度）。
2. **大幅减少 blur 滤镜**：轮廓锐利，雾气用「低透明度横向渐变矩形/椭圆 + 极小 blur（≤1）或多层叠淡」表达，禁止大面积 stdDeviation>2。
3. **小舟**：重画精致剪影（舟身弧线 + 船夫蓑笠，约 40–60px，完整置于水面线之上、不跨雾带），或干脆删除——二选一，交接说明选择理由。水面倒影与留白保留。
4. **天空**：保留暖纸色渐变；朱砂太阳保留并加柔和边缘光晕（径向渐变，不刺眼）。暗色主题适配：检查 Today.tsx 当前对该图的 CSS 处理（brightness/透明度），保证暗色下天空不过曝、墨山层次可辨。
5. viewBox 建议 1920×480（保持 slice 裁切语义），与 Today.tsx 的容器裁切方式核对一致。
6. 配套小图 empty-mountain.svg / mountains-vertical.svg（侧栏底部与空态）若同病（折线+糊）同步微调，保持同一家笔法；侧栏小图当前观感尚可，如改动需亮暗双态走查。
