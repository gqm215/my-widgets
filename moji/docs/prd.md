## 1. 产品概述
「墨集」— 墨色纸韵，一站式日程管理工具。一款融合东方禅意美学的综合日程管理工具，将笔记、备忘、待办、日程与日历功能集于一身，为追求专注与美感的用户创造沉浸式管理体验。

- 解决用户在日程、笔记、待办等事项管理中需要在多个应用间切换的痛点
- 为知识工作者和设计爱好者提供兼具效率与美感的统一管理工具

## 2. 核心功能

### 2.1 用户角色
无需复杂角色区分，面向普通用户提供完整功能体验。

### 2.2 功能模块
1. **今日视图**：今日概览、快捷操作入口、今日事项展示
2. **笔记模块**：Markdown 编辑器、笔记分类标签、搜索与收藏
3. **备忘模块**：快速记录、时间戳、转化为待办/日程
4. **待办模块**：任务管理、优先级设置、截止日期、筛选排序
5. **日程模块**：事件创建、时间管理、重复设置、提醒功能
6. **日历模块**：月视图、周视图、日期详情展示

## 3. 核心流程

### 3.1 主用户流程
用户打开应用，首先看到今日视图，可快速查看今日概览并新增事项。通过侧边栏切换不同功能模块，所有数据自动关联显示在日历视图中。

```mermaid
graph TD
    A["打开应用"] --&gt; B["进入今日视图"]
    B --&gt; C{"选择操作"}
    C --&gt;|查看概览| D["浏览今日事项"]
    C --&gt;|快速添加| E["新增待办/日程/笔记/备忘"]
    C --&gt;|切换视图| F["周历/月历/功能模块"]
    E --&gt; G["自动保存"]
    G --&gt; D
    F --&gt; D
```

### 3.2 新增待办流程
点击快捷添加按钮 → 选择类型 → 输入内容 → 设置时间/优先级 → 确认保存 → 自动显示在对应模块和日历中

```mermaid
graph LR
    A["点击 + 按钮"] --&gt; B["选择类型: 待办/日程/笔记/备忘"]
    B --&gt; C["输入内容"]
    C --&gt; D["设置时间和优先级"]
    D --&gt; E["回车确认"]
    E --&gt; F["自动保存并显示"]
```

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：墨色系（#1a1a1a, #2d2d2d, #4a4a4a, #8a8a8a, #e8e8e8）
- **强调色**：朱砂红（#c94043）、藤黄（#d4a84b）
- **背景色**：宣纸白（#faf8f5）、熟纸（#f0ece4）
- **字体**：标题 Noto Serif SC，正文 Noto Sans SC，英文 Crimson Pro
- **按钮风格**：柔和圆角 8px，纸张层叠阴影效果
- **布局**：侧边导航 + 主内容区 + 右侧详情面板
- **图标风格**：线性图标，线条粗细 1.5px，简约禅意

### 4.2 页面设计概述
| 页面名称 | 模块名称 | UI 元素 |
|-----------|-------------|-------------|
| 今日视图 | 侧边导航 | 墨色背景，宣纸白文字，线性图标，淡入淡出切换动画 |
| 今日视图 | 内容区 | 宣纸白背景，卡片式布局，柔和阴影，列表项依次渐现 |
| 笔记页面 | 编辑器 | 双栏布局，左侧墨色编辑区，右侧宣纸预览区 |
| 日历页面 | 月视图 | 网格布局，有事项的日期用朱砂红标记，悬停轻微上浮 |
| 全局 | 浮层 | scale 0.95→1 淡入动画，200ms 过渡 |

### 4.3 响应式设计
- **桌面优先**：1200px+ 完整三栏布局
- **平板适配**：768px-1199px，侧边栏可折叠为图标栏
- **移动端**：&lt; 768px，底部导航 + 全屏内容，详情面板全屏覆盖

### 4.4 动效设计
- 页面切换：淡入淡出 300ms ease-out
- 列表项：依次渐现 stagger 50ms
- 浮层弹出：scale 0.95→1 + fade 200ms
- 悬停效果：轻微上浮 + 阴影加深
- 完成动画：删除线渐显效果
