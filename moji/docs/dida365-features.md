## 一、应用整体结构

### 1.1 四区骨架（PC 端）

```
┌────┬──────────┬──────────────────┬──────────────────┐
│图标栏│ 导航栏    │ 主列表区          │ 详情区            │
│64px │ ~200px   │ 弹性              │ 弹性，可空态       │
└────┴──────────┴──────────────────┴──────────────────┘
```

- **图标栏**（最左竖条）：头像、任务、日历、专注、习惯、搜索、同步、通知、帮助等应用级入口，纯图标无文字（S1/S3/S7）。
- **导航栏**：智能清单（今天/最近7天/收集箱）→ 清单（含文件夹层级）→ 标签 → 过滤器（S1）。
- **主列表区**：当前清单的任务列表，顶部为清单标题 + 排序 + 「...」菜单（S1）。
- **详情区**：选中任务后展示；未选中时为空背景插画（S1 右侧）。

**经验**：详情区是常驻栏而非弹窗，选中即看、再选即换，没有打开/关闭成本；空态用淡插画填充避免「半截空白」的违和感。

### 1.2 导航栏分区顺序（S1）

| 分区 | 条目 | 附加信息 |
|---|---|---|
| 智能清单 | 今天 4 / 最近7天 4 / 收集箱 3 | 图标 + 未完成数角标 |
| 清单 | 备忘录、工作生活事务 6、体能训练·运动健身 3（子项：锻炼计划 3）、文化课程·科研竞赛…13（子项：文宣战研写作 3、科研竞赛项目、课程作业任务 10）、暑假假期 | emoji 图标 + 颜色圆点 + 角标；文件夹可折叠 |
| 标签 | 折叠分区，附说明文字 | 说明：「以标签的维度展示不同清单的任务。在添加任务时输入 # 可快速选择标签」 |
| 过滤器 | 折叠分区 | 内容未展开（未确认） |

**经验**：
- 「收集箱」是**未分配清单任务的默认归宿**，降低新建任务时的决策成本（先记下来，后再分类）。
- 清单用 **emoji + 颜色圆点**双标识，emoji 表意、圆点做跨视图的一致色（日历块、甘特条复用同色）。
- 角标只显示**未完成数**，已完成不占用视觉注意力。

## 二、清单体系

### 2.1 三层组织：文件夹 → 清单 → 任务（S6）

「添加清单」弹窗字段：

| 字段 | 内容 |
|---|---|
| 名称 | 文本输入，左侧可换图标 |
| 颜色 | 9 个色板：无 / 红 / 橙 / 黄 / 浅黄 / 绿 / 蓝 / 紫 / 自定义渐变色 |
| 视图 | 列表 / 看板 / 时间线 三种；**看板带皇冠标（会员功能）** |
| 文件夹 | 下拉单选：无 / 工作生活事务 / 体能训练·运动健身 / 文化课程·科研竞赛·宣传文字 / + 添加文件夹 |
| 类型 | 被遮挡（未确认） |
| 在智能清单中显示 | 开关（清单可决定是否参与「今天/最近7天」聚合） |

**经验**：
- **文件夹是清单的上层分组**，一个清单只属一个文件夹，不是任意深度树——两层足够，避免无限嵌套的管理负担。
- 「在智能清单中显示」让清单可以**退出全局聚合**（如「暑假假期」这类归档型清单不污染「今天」）。

### 2.2 清单「...」菜单（S12）

- 视图切换：列表 / 看板 / 时间线
- **隐藏已完成**（开关）
- **显示详细**（开关，任务行是否展开描述等信息）
- **显示设置**（更细粒度的字段级显示配置，未展开）
- **添加分组**（清单内自定义分组）
- 共享、清单动态、打印 ▸

**经验**：显示偏好（隐藏已完成/显示详细）挂在**清单级**而非全局，不同清单可以有不同密度——学习清单要详细，购物清单要紧凑。

### 2.3 清单内自定义分组（S12「添加分组」）

除「未完成 / 已完成」的系统分组外，用户可在清单内再建分组。具体交互未展开（未确认）。

## 三、任务列表

### 3.1 列表构成（S1）

- 顶部：**+ 添加任务** 内嵌输入框（非弹窗），回车即建、可连续添加
- 任务行：勾选框 + 标题 + 行内辅助信息
- **子任务缩进展开**：父任务行左侧折叠箭头，子任务缩进显示（如「操作系统实验作业 → 无标题」「操作系统原理作业 → 3.1 / 3.2」）
- **已完成分组**：底部独立折叠区，标题「已完成 5」，条目划线 + 勾选态（2.3/2.2/2.4/1.1）
- 截止日期右对齐显示（如「网安对抗大作业2 → 10月27日」）
- 含描述的任务，行首显示「描述」小图标（S5 通信原理作业行）
- 有子任务的任务，行尾显示子任务图标（S5）

**经验**：
- 添加框常驻列表顶部，**创建是零跳转的**；弹窗只用于编辑复杂属性。
- 已完成不删除、不隐藏，默认收进底部分组——保留「我做完过什么」的成就感，又不干扰待办。
- 行内图标承担「有无描述/有无子任务」的信息 scent，不用点开就知道任务丰满度。

### 3.2 任务右键菜单（S4）

| 分组 | 项 |
|---|---|
| 日期 | 4 个快捷图标（今天 / 明天 / 下周 / 自定义日历，图标语义未逐一确认） |
| 优先级 | **4 级旗帜：红 / 黄 / 蓝 / 灰（无）** |
| 结构 | 添加子任务、关联主任务 |
| 状态 | 置顶、**放弃** |
| 归类 | 移动到 ▸、标签 ▸ |
| 行动 | 开始专注 ▸ |
| 其他 | 创建副本、复制链接、打开便签、转换为笔记（截断） |

**经验**：
- **「放弃」是独立于「完成」「删除」的第三终态**——不做了但留痕，与「做完了」在统计上分开。
- 优先级用旗帜颜色表达，灰旗=无优先级，比三档更贴近真实使用（大量任务其实不需要标级）。
- 右键菜单把最高频操作（日期、优先级）做成**图标直点**，不用进二级菜单。

## 四、任务详情

### 4.1 布局（S4/S5/S10）

```
┌────────────────────────────────┐
│ ☐ | 📅 日期与提醒          📌置顶 │  ← 属性条
│ 任务标题（大字号）           ☰  │
│ 描述                            │
│ ☐ 子任务（可直接编辑）          │
│                                │
│ [富文本工具栏]                  │
│ 添加评论…            😊 🖼       │  ← 底部
│ 📚所属清单      ⚠ 🕐 💬 ⋯       │  ← 状态栏
└────────────────────────────────┘
```

- 标题大字号、可直接改
- 描述区下方直接列出**子任务**，子任务即点即改（S5「作业三」蓝色下划线输入态）
- 底部状态栏固定：**所属清单**（带颜色图标）+ 提醒 / 评论 / 更多入口

### 4.2 描述富文本工具栏（S11）

全屏 / H 标题 / **B 加粗** / **A 高亮（黄底）** / 待办勾选 / 无序列表 / 有序列表 / I 斜体 / U 下划线 / S 删除线 / …更多

**经验**：描述是**富文本 + 可嵌入待办项**，不是纯 Markdown——「任务里还能再列小勾选」让轻量拆解不必真的建子任务。

### 4.3 评论（S10）

底部「添加评论」输入框 + 表情 + 图片按钮。单人使用场景下等价于**带时间戳的追加备注**（任务动态见下）。

### 4.4 详情「...」完整菜单（S9）

添加子任务 / 关联主任务 / 置顶 / 放弃 / 标签 ▸ / **上传附件** / 开始专注 ▸ / **任务动态** / **保存为模板** / 创建副本 / 复制链接 / **打开便签** / **转换为笔记** / **打印** / 删除

与列表右键菜单的差异：多出上传附件、任务动态、保存为模板、打印、删除——** destructive 与低频操作收在详情，高频操作沉到列表右键**。

**经验**：
- 「任务动态」是操作历史流，与评论并列构成任务的「时间维度档案」。
- 「保存为模板 / 创建副本」面向重复性任务（每周例会、每月报销）。
- 「转换为笔记 / 打开便签」打通任务与长文内容：任务承载行动，笔记承载资料。

## 五、日历

### 5.1 迷你月历（S2 左栏）

- 月标题 + 左右翻页 + 回今天圆点
- **周日起始**（日一二三四五六）
- 日期下小字**农历**（十七、寒露、霜降、重阳节、万圣节、立冬等节气节日直接标注）
- 有事项的日期带**彩色圆点**（颜色对应清单色）
- 今天高亮

### 5.2 清单过滤（S2 左栏下部）

「所有」总开关 + 每个清单一个复选框——**日历可同时叠加多个清单**，勾选即过滤。

### 5.3 日视图（S2 主区）

- 顶部：+ 新建 / 视图切换（日▾）/ 左右翻页 / 今天 / …
- 日期大圆徽标 + 星期 + 农历（周六 · 初六）
- **全天/未排时任务块**置顶横条：蓝色=未完成、绿色=已完成，均带勾选框可直接操作
- 时间轴按小时分行（14:00–00:00），**当前时间红色横线 + 圆点**（19:54）

**经验**：日视图里任务不只是「展示」，勾选框直接可点——日历也是操作界面，不是只读报表。

### 5.4 周/月视图（P4）

月视图为整月网格 + 彩色事项条；周视图为 7 列 + 时间轴；顶部有今天、翻页、视图切换。

## 六、时间线（甘特）视图（S13）

- 清单内任务按**起止时间段**画横条，横轴为日期（周五9 → 周三21+）
- 今天所在列高亮；特定日期有红色标记（10 日）
- 条色 = 清单色；**已完成 = 实心绿，未完成/未开始 = 半透明**
- 顶部「今天」按钮 + 时间粒度切换（周▾）
- 示例：网安对抗大作业1（9→21 长条）、网安对抗大作业2（12 起）、通信原理作业（前两次）（20 起，半透明）

**经验**：甘特不必是项目管理的重型工具，**清单内一键切换**就是「这些任务在时间上的分布」，透明度区分完成态非常克制有效。

## 七、专注（S3）

- **全屏沉浸页**：大圆环进度 + 中央倒计时（00:46）+ 关联任务名（写作业 >）
- 主按钮随状态切换：「结束休息」（当前处于休息段）/「退出」
- 顶部：收起、**静音开关**、更多
- 右侧栏：
  - 关联任务卡（图标 + 标题 + 链接）
  - **时间轴展示今日专注块**（19:25–19:55 蓝色块，当前时间红点）
  - **专注笔记**：「记录你的想法…」文本框

**经验**：
- 专注与任务**双向关联**：任务菜单「开始专注」进入，专注页也能跳回任务。
- 「专注笔记」把专注期的灵光一闪就地接住，不用切窗口。
- 专注块直接画在时间轴上，与日程同坐标系——**专注记录 = 一种时间数据**，可进统计。

## 十一、可借鉴的设计经验提炼

1. **层级克制**：文件夹 → 清单 → 任务 → 子任务，四层封顶；不做无限嵌套。
2. **收集箱兜底**：新建任务默认有去处，分类是可选动作而非前置门槛。
3. **三终态**：完成 / 放弃 / 删除分开，「不做了」也有数据价值。
4. **创建零跳转**：列表顶部常驻输入框；复杂属性进详情，不用弹窗打断。
5. **详情常驻**：右栏详情随选中切换，无开关成本；空态用插画。
6. **高频操作图标化**：右键菜单里日期、优先级直接图标点选；destructive 操作收进详情菜单深处。
7. **颜色即语言**：清单色贯穿导航圆点、日历块、甘特条、专注块；蓝=进行中、绿=已完成、半透明=未开始，全局一致。
8. **密度按清单**：显示详细/隐藏已完成是清单级偏好，不是全局一刀切。
9. **时间数据打通**：任务、日程、专注块、习惯打卡共用时间轴坐标系，为统计/周报提供统一原料。
10. **任务↔笔记互通**：转换为笔记、打开便签、保存为模板，让行动与资料互相转化。
11. **农历与节气**：迷你月历直接标注，本土用户的日历刚需。
12. **会员功能标识**：看板视图带皇冠，商业化入口不打扰主流程。
